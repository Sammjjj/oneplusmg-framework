# Maturity Level Model

The Maturity Level Model (MLM) was developed by the Beyond One Million Genomes (B1MG) project to help countries and regions assess the maturity of genomic medicine practices in healthcare using a common framework.

## Explore the model

[**Open the complete Maturity Level Model, including the maturity matrix and glossary**]({{ '/maturity-model/view/' | relative_url }}){: .btn .btn-primary }

The model covers governance and strategy, investment and economic models, ethics and policy, public awareness, workforce skills, clinical organisation, clinical genomics and data management. The original B1MG validation rounds and glossary are retained in the source model view.

## About this resource

The model supports national and regional self-assessment of readiness to adopt genomics in healthcare. It originated from B1MG and is presented here as a resource within the wider 1+MG Framework.

**Source:** [B1MG Maturity Level Model](https://b1mg-project.eu/resources/maturity-level-model) | [Source code](https://github.com/B1MG-project/MLM)

The imported model preserves the GitHub source wording. Differences from the currently published B1MG webpage have not yet been completely verified.
