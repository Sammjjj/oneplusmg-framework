What do these resource labels mean?

In order to determine the importance of each resource for development of each Node, most resources are labelled with one of the following tags:

{% include resource-marker.html recommendation="Required" %}
Some or all of this resource is required for being part of this infrastructure. In some cases (particularly with the policies) some parts of the resource will be optional (and will be labeled with the language “may”, “should”, or “must” as appropriate), however some elements are required and are thus given this overall label.
{% include resource-marker.html recommendation="Recommended" %}
While not integral to being part of the infrastructure, these are helpful resources which will help you align across Europe and beyond and have been vetted by the project teams.
{% include resource-marker.html recommendation="Informational" %}
These are resources that serve as guides and background information.
